# Delivery Quote CLI 명세

입력: `decisions.md`(D-1..D-9 확정, A-1..A-3 에이전트 제안, U-1 미정). 산출 스킬: `spec`. 재인터뷰 없음. 이 문서는 명세이며 구현 완료를 뜻하지 않는다.

## 1. 문제와 범위

호출자가 정수 weight 하나로 배송 금액을 조회한다. 금액 또는 기계 판독 가능한 오류를 process 공개 행동으로 돌려준다.

- 목표: `python quote.py <weight>` 공개 계약 제공.
- 비목표: 성능 SLO, 인증, 저장, 외부 서비스(D 출처: 사용자 확정 해당 없음). tracker 게시, 배포.
- Actor: CLI 호출자 1종, 권한 구분 없음.
- 파일 경계: 제품 `quote.py`, `test_quote.py`만. 표준 라이브러리만(D-8).

## 2. Use case

| 항목 | 내용 |
|---|---|
| 시작 조건 | Python 3.12 실행 가능, 사전 상태 없음 |
| 입력 | 명령행 위치 인수 weight |
| 정상 결과 | exit 0, stdout 금액 JSON, stderr 비어 있음 |
| 실패 결과 | exit 2, stdout 비어 있음, stderr 오류 JSON, traceback 없음 |
| 복구 | 유효 입력으로 다시 실행하면 성공. 이전 실패 영향 없음 |
| 변경되지 않을 데이터 | 저장 데이터 없음. 실행은 파일을 만들거나 변경하지 않음 |

성공 시 stderr 비어 있음은 D-4가 직접 규정하지 않은 사항이며 A-3의 출력 형식 제안에 포함해 조건부로 다룬다(AC-1c).

## 3. 도메인

- `weight`: 유효 범위 1..10의 정수. 단위 미정(U-1).
- `total`: 정수 금액. 통화 미정(U-1).
- `shipment`(D-1): weight 검증과 가격 규칙 소유. 잘못된 입력은 도메인 오류 `InvalidWeight`로 표현하며 JSON과 exit code를 알지 못한다.
- CLI adapter(D-2): `sys.argv`를 `shipment`에 전달하고 결과를 JSON과 exit code로 변환한다. 가격이나 범위 정책을 갖지 않는다.
- 구조(D-9): 두 경계 모두 `quote.py` 안의 함수/오류 경계로 구분한다.
- 불변식: 유효 범위 밖 weight에는 가격이 없다. 상태 전이 없음(stateless).

## 4. 외부 계약

성공(D-4):

```text
$ python quote.py 1
{"total":5000}
exit 0
```

가격(D-3): 1..5 → 5000, 6..10 → 8000.

실패(D-5), 0, 11, 비정수, 인수 누락:

```text
stdout: (비어 있음)
stderr: {"error":"INVALID_WEIGHT","retryable":false}
exit 2
```

조건부(에이전트 제안, 승인된 사실 아님):

- A-1: `[1-9][0-9]*` 전체 일치만 정수로 인정. `" 1"`, `"+1"`, `"01"`, `"1_0"`, 비ASCII 숫자는 INVALID_WEIGHT.
- A-2: 인수 2개 이상은 INVALID_WEIGHT.
- A-3: 성공 시 stderr는 비어 있음. JSON의 compact 출력은 구현 선택이며 직렬화 원문은 계약이 아니다(build 단계 갱신, `decisions.md` A-3 참조).

호환성/중복 요청: 부수효과가 없어 중복 실행은 같은 결과다. 버전 관리 계약은 해당 없음.

## 5. 공통 책임

| 영역 | 내용 |
|---|---|
| 오류 | `INVALID_WEIGHT`: 분류 호출자 입력 오류. 의미는 `shipment`, 외부 변환은 adapter. 노출 정보는 코드와 `retryable:false`만. |
| 인증, 설정, 로깅, 외부 접근, retry | 해당 없음. stateless 로컬 CLI이고 사용자가 인증/저장/외부 서비스를 해당 없음으로 확정. 추적 정보 없음. |

## 6. 운영 조건

성능 SLO, 인증, 저장, 외부 서비스 해당 없음(사용자 확정). 규모, 비용, 복구 목표를 만들지 않는다.

## 7. 기술과 의존성

Python 3.12 표준 라이브러리 고정(D-8). 후보 비교와 최신성 조사는 사용자 지시로 수행하지 않는다. 확인된 로컬 버전: Python 3.12.15. 공통 기반 선행 작업 없음.

## 10. 미정과 NOTRUN

- U-1: weight 단위와 total 통화. 공개 동작 영향 없음. 사용자가 지정하면 문서만 갱신.
