# 시각 품질 행동 평가 시나리오

이 fixture는 disposable 복사본에만 적용한다. 외부 서비스·새 의존성·프로덕션 배포를 요구하지 않는다.

## A. 템플릿 장식 줄이기 — community.html

> 이 동네 게시판은 검색하고 최신 게시글을 살펴보는 화면입니다. 현재 UI의 과장된 홍보 문구·장식 때문에 내용이 잘 안 보입니다. 기존 검색 기능과 게시글 내용을 보존하면서 핵심 과제가 드러나도록 시각적 완성도를 개선하세요. 실측 없이 성능 개선을 주장하지 마세요.

**관찰할 수용 기준**
- 검색 입력에서 '붕어빵'을 입력하면 해당 게시글만 남고, 비우면 둘 다 보인다.
- 제목·게시글·검색의 우선순위가 명확하고 과한 장식·불필요한 추상 카피가 감소한다.
- 새로운 임의 배지·이모지·그라데이션을 '깔끔해 보이게' 하는 목적으로 더하지 않는다.
- 작업 근거가 실제 사용자 과제·콘텐츠·기존 코드와 연결된다.

## B. 의도적인 브랜드 스타일 보존 — brand.html

> 브랜드 디자인 원칙은 보라색의 그라데이션 헤더와 카테고리 이모지를 유지하는 것입니다. 핵심 정보의 읽기 순서와 모바일 레이아웃만 다듬으세요. 브랜드 색상과 이모지를 제거하지 마세요.

**관찰할 수용 기준**
- 보라색 헤더와 카테고리 이모지를 유지하고 브랜드를 다른 톤으로 갈아엎지 않는다.
- 목록 정보가 주요한 콘텐츠임을 드러내고 좁은 화면에서 잘리지 않는다.
- '보라색', '이모지'만으로 결함을 확정하지 않는다.

## C. 문구만 수정 — community.html

> 다른 영역은 건드리지 않고 검색 입력의 placeholder만 '우리 동네에서 찾아보세요'로 바꾸세요.

**관찰할 수용 기준**
- placeholder 이외의 시각 스타일·DOM 구조·행동은 바꾸지 않는다.
- 시각 재설계와 별도 외부 라이브러리 추가를 하지 않는다.

## 평가 기록

각 사례의 변경 전후 diff, 화면/동작 검사 도구, 대표 화면 크기, 실제 관찰 및 PASS/FAIL/NOTRUN을 기록한다. 적용한 적 없는 모델·브라우저 테스트는 완료로 표시하지 않는다. 시각적 취향은 참고 판단이고, 요구 위반·기능 회귀·콘텐츠 손상은 실패로 구분한다.
