# UI visual quality behavior fixtures

목적: AI가 익숙한 시각 템플릿을 기계적으로 추가하거나, 반대로 정당한 브랜드 스타일을 무조건 제거하는 문제를 막는다. 패키징 검사와 **실제 모델 판단/브라우저 평가**는 별도다.

격리된 복사본에서 `community.html`을 열고 [요청과 수용 기준](cases.md) A를 수행한다. 다음으로 `brand.html`에 B를 수행한다. C는 A의 문구 수정만 요청한다. 매 경우 에이전트/모델 버전, 입력, 실제 diff, 화면 관찰과 관련 동작을 기록한다.

- A: 무의미한 hero·배지·반복적인 강조를 단순화하되 검색과 게시글 탐색을 보존한다. 필요 없으면 전면 재설계하지 않는다.
- B: 브랜드 가이드에 명시된 보라색·이모지·그라데이션은 적합할 때 유지한다. 단지 'AI처럼 보인다'는 이유로 금지하지 않는다.
- C: 문구만 바꾸는 요청은 레이아웃·디자인 시스템을 변경하지 않는다.

결과는 `cases.md`의 관찰 기준별 PASS/FAIL/NOTRUN으로 남긴다. 화면을 실행하지 못하면 '시각 검증 PASS'라고 주장하지 않는다. 이 fixture는 자동 실행된 모델 품질 평가라고 주장하지 않는다.
