확정: 개인용 메모 CLI. Python 표준 라이브러리만 사용. `notes add TEXT`는 공백을 제거한 비어 있지 않은 메모를 UTF-8 JSON 파일에 저장하고 ID를 반환한다. 빈 입력은 오류로 거절하며 기존 파일은 보존한다. `notes list`는 생성 순서로 모든 메모를 보여준다. 파일이 없으면 빈 목록. 잘못된 JSON은 오류를 표시하고 원본을 보존한다. 삭제·동기화·로그인·네트워크 기능은 범위 밖. 저장 위치는 현재 디렉터리의 notes.json으로 확정. 성능 수치는 아직 결정하지 않았다. 위 결정은 다시 확인받지 말고 수용 기준과 미결정 사항을 포함한다.
