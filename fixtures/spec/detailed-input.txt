$spec 아래 확정 대화로 구현 가능한 상세 명세를 작성한다. 재인터뷰나 shape 호출은 필요 없다. 파일/외부 게시/구현은 하지 말고 답변으로 작성한다.

확정: 기존 Python 표준 라이브러리 HTTP 서비스와 SQLite를 유지하는 단일 프로세스 회의실 예약 도구다. 인증 adapter가 user_id와 role(member/admin)을 제공하며 로그인 구현은 범위 밖. 회원은 본인 예약 생성/취소, 관리자는 모든 예약 취소 가능. room_id, UTC start/end, owner_id를 보관한다. start < end이며 같은 방의 active 예약은 겹칠 수 없다. cancelled는 재활성화하지 않는다. 취소 재요청은 성공 no-op. 존재하지 않는 예약은 404, 타인 취소는 403이며 상태는 그대로 유지한다. 충돌 생성은 409이며 기존 예약을 보존한다. 예약 도메인은 Overlap/Forbidden/CannotTransition의 의미를 소유한다. 중앙 HTTP handler는 도메인 오류를 code/message/trace_id로 변환하고 내부 SQL/stack을 숨기며 한 번 로깅한다. 저장소 장애는 503 retryable, 재시도 시 서버 중복 생성 방지를 위해 요청 idempotency key를 사용한다. 이 key와 예약은 같은 transaction에 저장하고 같은 key/같은 payload는 기존 결과, 같은 key/다른 payload는 409로 확정. 결제/알림/microservices는 범위 밖. 성능 SLO와 보관 기간은 미정이다. API path와 ID 형식은 되돌릴 수 있는 제안으로 써도 된다.
