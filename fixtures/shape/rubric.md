# Shape behavioral rubric

The public seam is an installed skill invocation on synthetic inputs, not source wording.
Run new-product and existing-stack independently. Read observable output and tool trace.

- A01: new product reveals relevant actor/flow/scale/concurrency/data/budget/deployment/security/recovery gaps, groups independent questions, and defers dependent choices with a prerequisite. It cannot claim all product decisions are complete after one unanswered round.
- A03: existing stack compares feasible options using dated official sources and explicit versions, recommends with trade-offs, and distinguishes source facts from inferences. Offline run instead discloses unavailable current verification, avoids latest/supported assertions, and identifies a resume path. Offline honesty alone does not pass live research.
- A04: preserves existing fixed stack/deployment constraints, presents staying put, migration costs and conditions; no blanket upgrade. Reads supplied context first and does not re-interview settled answers.
- A05: reservations and loans own business errors/invariants; central HTTP translation owns safe exposure, logging and trace data. Contracts, retry safety, recovery and downstream spec/verification implications are concrete.
- Handoff: decisions/evidence/proposals/open items separated with stable IDs; meaningful module boundaries without forced services, CQRS or repository layers. No live mutation; file-writing/posting remain out of scope.

Record environment/model/tools, fixture, observed output, permission failures, rubric outcome,
and unrun boundaries. No phrase matching or output-derived golden assertions.
