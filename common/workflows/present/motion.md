# 이해를 돕는 모션

순차적 설명, 인과관계, 전후 비교의 초점 이동, 장면의 등장 리듬이 필요한 경우 읽는다. 모든 장에 동일한 fade/stagger나 장식 loop를 붙이지 않는다. 표현하려는 관계가 없으면 정적인 구도가 더 낫다. 단순 전환은 CSS로, 복합 순서·재생 제어는 GSAP timeline처럼 명시적으로 제어 가능한 도구로 구현한다.

GSAP을 사용할 때 실제 버전의 공식 문서 또는 호스트에 있는 공식 전문 스킬에서 필요한 core/timeline 절차만 확인한다. React·ScrollTrigger를 기본 의존성으로 넣지 않는다. 라이브러리를 가져올 수 없으면 CSS/정적 대안과 차이를 알리고 CDN 의존성을 숨기지 않는다.

- 각 장의 timeline을 해당 장에 한정하고 활성 장만 재생한다. 이동 시 중단/정리하고 재진입 정책을 일관되게 적용한다.
- 빠른 다음/이전 입력, 중간 이동, resize, 직접 장 링크에서도 본문이 반쯤 사라지거나 이전 animation이 뒤늦게 실행되지 않아야 한다.
- 순서는 timeline/label로 관리하며 임의 setTimeout을 누적하지 않는다. transform/opacity를 우선하고 대량 레이아웃 측정/변경을 교차 반복하지 않는다.
- reduced-motion이면 핵심 내용을 즉시 표시하고 조작은 그대로 유지한다. 인쇄/읽기 모드도 최종 상태로 표시한다.
- 자동재생보다 발표자가 설명 속도를 통제하게 한다. 움직임을 보느라 내용을 읽기 어려우면 줄인다. 생성 이미지에 모션을 줄 때 텍스트를 함께 흔들거나 가독성을 낮추지 않는다.

모션이 예쁜지는 정지 캡처로 검증할 수 없다. 실제 전환과 중단/재진입을 실행해 확인한다.
