# 타입과 색의 역할

타이포그래피·색 체계를 정하거나 수정할 때 적용한다. 기존 브랜드의 의도적인 선택은 보존한다.

- 제목·본문·보조 정보·수치의 역할별로 크기·굵기·행간을 함께 고른다. 역할을 추가하기 전에 기존 토큰으로 위계가 전달되는지 확인한다. 줄 수·언어·실제 글꼴과 fallback에서 읽어 보며 짧은 영어 예시만으로 한국어 본문을 판단하지 않는다.
- 제목의 줄 균형, 본문의 읽기 폭과 행간, 긴 값의 줄바꿈/전체 값 접근을 구분해 결정한다. 수치의 비교와 갱신이 중요하면 숫자 폭·정렬이 안정적인지 확인한다. 특정 글꼴·크기·CSS 속성을 모든 제품에 강제하지 않는다.
- 색은 배경/표면·주요/보조 텍스트·행동·상태 같은 의미로 이름 붙이고 실제 토큰을 재사용한다. 강조색을 늘리기 전에 중요도와 상태 의미를 분리한다. 의미는 색 외에 문구·형태로도 전달한다.
- 실제 전경/배경 조합, 상태와 테마에서 대비를 측정한다. 저대비를 고급스러운 스타일로 정당화하지 않는다. 적용 기준이나 지원 여부가 불명확하면 [research](../research.md)로 공식 근거를 확인한다. 팔레트 형식 변환 자체를 품질 향상으로 주장하지 않는다.
- 렌더링이 없으면 추천 토큰과 확인할 조건까지만 남긴다. 소스의 색 값·글꼴 선언만 보고 실제 대비·가독성을 통과 처리하지 않는다.
