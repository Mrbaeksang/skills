# 발표의 이야기와 시각 방향

## 의미를 먼저 보존한다

기존 자료 개선은 각 장의 역할, 연결 문장, 사실/인용/예시, 꼭 남길 내용을 먼저 파악한다. 새 사례가 원래 주장을 증명하는지, 단지 생각할 계기를 주는지 구분한다. 사례를 추가하면서 발표를 다른 주제로 바꾸거나 원래의 실천 방법을 지우지 않는다. 발표용은 말로 보완할 여백과 박자를, 읽기용은 독립적으로 이해할 맥락과 주석을 준다. 정해진 장수에 맞춰 글씨를 줄이지 않는다.

장면별로 청중이 가져갈 메시지를 한 문장으로 정하고, 주장에는 맞는 근거를 둔다. 질문·표지·전환까지 모두 결론형 제목으로 강제하지 않는다. 숫자·인용·실제 인물·성과는 확인된 원자료에만 근거한다. 원문을 읽지 못했거나 사례의 조건이 불확실하면 불확실성을 감추지 않는다. 출처는 해당 장에서 접근할 수 있게 하며 생성 일러스트를 실제 사진/실험 결과로 오인시키지 않는다.

외부 사례는 제목·링크만으로 설명을 대신하지 않는다. 무엇을 어떤 조건에서 했고, 실제로 무엇이 달라졌으며, 청중이 왜 이 사례를 보는지 이해할 최소 맥락을 담는다. 관찰된 결과와 발표의 교훈을 분리하고, 확인하지 못한 결과를 채워 넣지 않는다. 주의 문구가 사례 설명 자체를 밀어내지 않게 한다.

## 내용이 구도를 결정한다

청중과 주제에 어울리는 아트디렉션을 하나 정한다: 읽는 순서, 글자 크기/굵기 대비, 색의 역할, 여백, 이미지의 역할, 장면 전환의 리듬. 브랜드/레퍼런스가 있으면 그 의도를 읽고 재사용한다. 모든 자료를 같은 어두운 배경·그라데이션·카드 3개로 만들지 않는다. 반대로 특정 색·폰트·카드 자체를 금지하지도 않는다.

- 주장: 큰 문장과 이를 뒷받침하는 한 장면. 장식을 위해 근거 없는 숫자를 추가하지 않는다.
- 비교: 공통 축을 가진 좌우 대비·표·직접 라벨. 긴 두 문단을 작은 글자로 나란히 놓지 않는다.
- 과정/관계: 흐름·위계·시간 순서를 도식으로 표현한다. 단순 아이콘 나열로 관계를 대신하지 않는다.
- 실제 제품/사례: 필요한 부분이 보이는 원본 화면·사진과 짧은 주석. 작은 전체 화면을 장식용으로 넣지 않는다.
- 마무리: 청중이 바로 해볼 행동과 기억할 메시지. 일반적인 감사 문구만으로 끝내지 않는다.

내용에 따라 장면의 밀도와 구도를 바꾸되 정렬·타입·색 체계는 일관되게 유지한다. 시각 방향이 불명확할 때만 실제 내용이 담긴 대표 장면을 비교한다. 표지만 예쁘고 본문이 같은 카드 반복인 결과는 다시 편집한다. 취향 선택을 위임받았다면 스스로 고르고 설명 때문에 제작을 멈추지 않는다.

## 한국어와 화면 가독성

한국어 기본 글꼴은 사용 가능한 Pretendard 같은 한글/영문/숫자 조합이 안정적인 서체를 우선한다. 브랜드 서체가 있으면 존중한다. 글꼴 이름은 가독성 검증을 대신하지 않는다. 본문 굵기·행간·문장 길이·숫자와 기호·실제 폰트 로드를 확인한다. 한글은 자연스러운 어절 단위로 끊고 긴 URL·식별자는 별도 줄바꿈 규칙을 둔다. 제목의 마지막 한 글자만 다음 줄에 남거나 본문이 한 덩어리가 되면 문구와 폭부터 고친다.

목표 화면에서 실제로 표시되는 글자 크기로 판정한다. 큰 고정 canvas 내부의 px만 보고 통과시키지 않는다. 기본은 PC 웹 발표이며 큰 발표 화면과 일반 노트북 높이에서 핵심 문장을 읽을 수 있게 만든다. 모바일 공유가 명시된 경우에만 읽기 모드나 적절한 재배치를 설계한다. 요청 없는 모바일 모드·추가 UI를 만들지 않는다. 단순 전체 축소는 모바일 가독성의 증거가 아니다. 넘치면 재편집/분할하고 clipping이나 일괄 축소로 감추지 않는다.

일반 글자 대비 4.5:1, 큰 글자 3:1을 최소 기준으로 점검하되 투사 환경과 얇은 글자는 더 보수적으로 본다. 사진 위 글자·보조 설명·차트 라벨도 포함한다. 화면별 검수가 전체 접근성 인증을 뜻하지 않는다.
