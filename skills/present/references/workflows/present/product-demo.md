# 제품을 보여 주는 장면

제품의 사용 과정을 짧은 시연으로 설명할 때만 읽는다. 일반 발표나 정적인 화면 비교에 시연·모션을 추가하지 않는다.

- 청중에게 전달할 사용자 행동 → 눈에 보이는 변화 → 얻는 결과를 정하고 필요한 장면만 남긴다. 실제 제품의 글자·상태·스타일을 사용하며 설명용 모의 화면은 실제 연동/실행 증거와 구분한다.
- 발표 크기에서 중요한 조작과 결과가 읽히도록 구도를 잡는다. 전체 앱을 작게 축소하거나 관련 없는 화면을 장식으로 쌓지 않는다. 실제로 제공하지 않는 성공·성과를 연출하지 않는다.
- 결과를 읽을 시간을 확보하고 반복 재생한다면 마지막→처음의 초기화도 확인한다. 자동 재생이 없거나 reduced motion인 경우에도 대표 정지 장면에서 핵심 결과가 전달되어야 한다.
- 실제 속도의 재생·중단·재진입과 최종 정지 장면을 확인한다. 정지 캡처로 모션 품질을 판정하거나 모의 시연으로 제품 기능 검증을 대체하지 않는다. 특정 프레임워크·라이브러리·길이를 필수로 만들지 않는다.
