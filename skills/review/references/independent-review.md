# 독립 검토와 완료 gate

인증·결제·데이터 변경의 검토는 실행자와 구분된 agent/검토자 또는 fresh session에서 수행한다. 같은 구현 세션의 역할 선언이나 자기 점검은 독립 검토가 아니다. 사용 가능한 위임 도구 또는 별도 실행 환경이 있으면 허용 범위에서 사용한다. 없으면 독립 검토 NOTRUN, 구체적 원인, 재개 조건을 보고한다.

검토자에게 고정된 base/head, 명세·적용 지침, raw diff와 필요한 source, 실행 권한 및 환경을 전달한다. 구현자의 결론·예상 finding·정답을 주입하지 않는다. 검토자는 원자료를 직접 확인하고 반증 가능한 근거로 판단한다. 실제 검토 주체/방식과 산출물 위치를 남기되 비밀정보와 runtime session ID는 배포 산출물에 넣지 않는다.

build에 돌려줄 증거는 범위, 독립성, findings, 각 finding의 해결/미해결 상태와 재검증, 필수 기준별 PASS/FAIL/NOTRUN이다. 미해결 고위험 finding, 필수 검증 FAIL/NOTRUN, 필요한 독립 검토 미수행이 있으면 done이 아니다. 고위험은 우선순위 표기만이 아니라 인증 우회·결제 오류·데이터 손실 등의 실제 영향으로 판단한다. 수정 뒤 새 head와 영향을 받은 경로를 재검토하고 원래 finding의 해소 근거를 남긴다. 이전 head에 대한 승인으로 새 변경을 자동 승인하지 않는다.
