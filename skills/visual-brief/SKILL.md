# Visual Brief

[공통 실행 계약](references/execution-contract.md)과 [읽기 쉬운 문서 작성](references/workflows/visual-brief.md)을 적용한다. 입력은 원자료와 읽는 목적이다. 문서 초안은 채팅에 제공한다. 단일 HTML을 요청하면 [기본 틀](assets/template.html)에서 시작한다. 기존 문서의 부분 수정은 지정된 작업본에 적용한다.

“이 계획 어때?”처럼 의견을 묻는 대화에서는 질문에 바로 답한다. 발표용 슬라이드와 제품 화면은 각각의 제작 절차를 따른다.
