# 지목된 원본은 끝까지

사용자가 특정 저장소·문서·예제·선행 구현을 지목하면 그것이 1차 근거다. 제목과 일부만 보고 요약하지 않는다.

## 신호

- 사용자가 "내 레포", "이 문서", "이 방법론", "이 오픈소스"를 참고하라고 한다.
- 다른 곳의 방법을 차용·이식한다.
- 비교·추천을 하는데 근거가 기억에 있다.

## 확인할 질문

1. 지목된 자료에서 결정에 영향을 주는 부분은 어디인가: 개요 문서, 규칙 문서, 예제 코드, 테스트, 측정 기록.
2. 이 자료가 이미 실측이나 실패에서 얻은 규칙을 담고 있는가. 그 규칙의 전제가 현재 프로젝트에도 성립하는가.
3. 비교 대상 중 실제로 읽은 것과 기억으로 말하는 것은 무엇인가.

## 수행

- 결정에 관련된 문서와 예제를 끝까지 읽는다. 양이 많으면 전부 읽는 대신 관련 범위를 정하고, 그 범위는 빠짐없이 읽는다.
- 차용할 부분과 현재 프로젝트 조건 때문에 그대로 쓸 수 없는 부분을 구분하고 이유를 남긴다.
- 외부 자료는 현재 공식 출처를 확인한다. 확인하지 못하면 기억에 의한 진술로 표시한다.

## 보고

- 읽은 파일·문서와 읽지 않은 범위를 밝힌다. "봤다"는 실제로 읽은 범위에 한정한다.

## 예

- 사용자의 쿡북 저장소를 참고하라는 요청 → 문서 두 개를 훑는 대신 관련 문서와 예제·테스트를 읽고 이식할 계약과 버릴 부분을 나눈다.
