# 프로젝트 작업 지침

현재 저장소와 요청 범위를 확인하고 [프로젝트 지침 관리](references/workflows/project-guide.md)를 수행한다. 기존 지침이 충분하면 확인한 근거로 끝낸다. 플러그인 설치나 일반 개발 요청만으로 프로젝트를 초기화하지 않는다.
