# Polish

기존 UI·사용자 문구의 정리·완성도를 개선한다. 입력은 대상 화면/문구, 사용자의 과제, 기존 브랜드와 보존할 동작이다. 새 제품 설계나 전면 redesign으로 확대하지 않는다.

1. 실제 콘텐츠, 사용자 과제, 기존 component·token·용어를 확인한다. [UI·문구 기준](polish/ui-copy.md)으로 정보 위계·불필요한 장식·추상적인 카피·동작과 다른 안내를 점검한다. 시각적 설계/수정일 때만 연결된 시각 품질 기준을 적용하고 취향과 관찰 가능한 사용성 문제를 구분한다.
2. AS-IS에서 확인한 문제에 대응하는 최소 변경을 한다. 새 장식·배지·강조의 이유를 제품 맥락으로 설명할 수 있어야 한다. 기존 브랜드와 동작을 보존하고, 색·글꼴·카드 자체를 금지하지 않으며 근거 없는 수치·후기·로고를 만들지 않는다. 같은 행동의 이름·오류 후 복구 안내를 실제 동작에 맞춘다.
3. 구현된 화면을 바꿨으면 [verify](verify.md)로 관련 화면 크기·상태·조작·focus 회귀를 확인한다. 시각 변경은 가능한 경우 동일 조건의 이전 화면과 비교하되, 문구 초안만 다루면 의미·사실·용어 일관성을 직접 확인하고 브라우저 검증을 발명하지 않는다.

짧게 수정 결과와 미확인 사실을 보고한다. 성능 개선을 주장하려면 별도 측정이 필요하며 이 절차를 성능 검증으로 대신하지 않는다.
