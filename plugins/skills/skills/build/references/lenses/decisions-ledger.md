# 결정과 위임 재사용

이미 허용된 작업은 반복 승인받지 않는다. 이전 작업의 권한을 새 작업으로 확대하지 않는다.

## 신호

- 승인 전에 같은 행동에 대한 기존 결정·위임이 발견됐다.
- 현재 요청과 이전 기록의 적용 범위가 다르거나 불명확하다.

## 확인과 수행

1. 현재 대화와 작업 기록에서 원문·대상 자원·환경·행위·조건·유효 범위를 확인한다. 지속 위임은 사용자가 이후 적용을 명시한 범위만 재사용한다. 같은 프로젝트나 같은 종류라는 이유만으로 대상을 넓히지 않는다.
2. 현재 요청이 이미 승인된 범위 안이면 재질문 없이 진행한다. 특정 작업의 일회성 승인이나 에이전트의 해석을 지속 권한으로 승격하지 않는다.
3. 최신 사용자 지시·프로젝트 규칙·권한 축소나 철회가 우선이다. 대상·환경·효과가 달라 범위 밖이면 그 차이에 필요한 결정만 묻고, 독립적으로 가능한 작업은 계속한다. 파일 쓰기 허용을 push·병합·배포·외부 제출 허용으로 해석하지 않는다.
4. 조회 가능한 사실과 되돌릴 수 있는 통상 구현 선택은 직접 해결한다. 질문이 필요하면 독립 질문을 묶고 추천안을 제시한다.

지속 결정은 [프로젝트 기억](../project-memory.md)의 원본 연결 방식으로 보존한다. 원문과 에이전트의 해석을 구분하고, 근거를 찾지 못하면 과거 승인을 지어내지 않는다. 사용자에게는 판단에 필요한 범위 차이만 짧게 알린다.
