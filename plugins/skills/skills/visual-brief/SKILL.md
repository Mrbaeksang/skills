# Visual Brief

[공통 실행 계약](references/execution-contract.md)과 [한 페이지 설명 문서 제작](references/workflows/visual-brief.md)을 적용한다. 입력은 전달할 내용, 독자, 이미 결정된 범위, 필요하면 기존 문서나 근거 자료다. 글 초안 요청이면 채팅에 완성 문안을 준다. HTML 요청이면 [HTML 틀](assets/template.html)을 복사해 실제 내용으로 완성한다. 기존 HTML의 국소 수정은 지정한 문서에 이어서 한다.

사용 예시 · “두 화면의 내보내기를 공통 기능으로 옮기는 계획이야. 무엇부터 하는지, 화면별로 뭐가 달라지는지, 남은 결정을 한 페이지 HTML로 공유할 수 있게 정리해줘.”
