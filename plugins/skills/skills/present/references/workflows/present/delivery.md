# 하나로 전달되는 HTML

기본 결과는 서버·빌드·설치 없이 직접 열리는 HTML 하나다. 제작 중에는 자산과 소스를 분리해도 되지만 전달본은 CSS, JS, 폰트, 이미지, SVG를 내장한다. JS/CSS CDN, 원격 font import, 상대 이미지 경로, 외부 SVG image, fetch에 필수 콘텐츠를 의존하지 않는다. 출처로 이동하는 링크는 실행 의존성과 다르다. 동영상처럼 큰 외부 자료는 임베드 재생을 오프라인 가능하다고 주장하지 말고 포스터/출처 링크와 제한을 알린다.

HTML/CSS와 작은 JavaScript로 충분하면 프레임워크를 도입하지 않는다. GSAP이 필요한 경우 선택한 공식 배포 버전의 코드를 내장하고 고지를 보존한다. 폰트도 라이선스/저작권 고지와 함께 내장한다. 폰트·이미지는 실제 출력에 필요한 크기와 굵기로 제한하고 파일 크기를 확인한다. 수정 폰트의 명칭/배포 조건을 확인하지 않고 임의로 subset하지 않는다. 사용자 비밀·로컬 경로·제작 중 메모는 전달본에 남기지 않는다.

선택한 서체를 CSS font-family에 적는 것과 실제 제공하는 것은 다르다. 기존 자료에 사용 가능한 내장 폰트가 있으면 보존하고, 새 자료는 배포 가능한 공식 font 파일을 data URI의 @font-face로 넣는다. 기존 폰트가 일부 글자만 담은 subset이면 새 문구까지 지원하는지 확인한다. 시스템 폰트 목록만 둔 결과를 동일한 타이포그래피가 보장되는 전달본이라고 보고하지 않는다. 폰트 확보가 불가능하거나 사용자가 시스템 폰트를 선택한 경우에만 fallback을 사용하고, 대체 서체에서 다시 검수한 결과와 기기별 차이를 알린다.

발표자가 진행하는 자료는 장 이동·현재 위치·키보드처럼 필요한 조작만 둔다. 웹으로 구현한다는 이유로 복사 버튼·읽기 모드·출처 패널·도구 모음·목차를 일괄 추가하지 않는다. 청중이 직접 사용하거나 배포 후 읽는 용도에서 필요한 기능만 선택한다. 읽기용은 연속 스크롤 등 내용에 맞는 구조를 선택할 수 있으며 슬라이드 navigation을 강제하지 않는다. fullscreen을 제공하면 사용자 동작으로만 요청하고 거부돼도 발표가 가능해야 한다. 장 이동을 제공하면 새로고침/직접 장 링크에서 같은 장으로 복원한다. 입력창·편집 중인 내용·링크의 키 조작을 navigation이 가로채지 않는다. 비활성 장이 있으면 focus와 접근성 트리에서 제외한다. 사용하지 않는 빈 notes/editor/panel 기능을 만들지 않는다.

민감정보를 가려 원문을 공유할 때는 배포 가능한 쪽을 먼저 정하고, 정보를 제거한 문서나 가림을 픽셀에 반영한 이미지로 내장한다. 화면 뒤의 원본 PDF·이미지, 숨은 텍스트, 링크 대상, 메타데이터, 발표 노트에도 가린 값이 남는지 확인한다. 원문을 투사 화면에서 읽기 어렵다면 미리보기에서 확대해 읽을 수 있게 한다. 여러 쪽을 공유할 때는 요청된 마지막 쪽까지 열 수 있어야 한다.

발표 노트는 숨겨 보여도 파일에 포함되면 수신자가 읽을 수 있다. 비공개 메모를 그대로 포함하지 않는다. 인쇄를 제공하면 숨겨진 장·단계별 등장 요소도 모두 표시하고, 한 장이 잘리거나 과도한 빈 페이지가 생기지 않도록 별도 print CSS를 둔다. 정적 읽기/인쇄에서 애니메이션 재생을 기다려야 본문이 보이는 구조는 피한다.

투사하는 발표 화면에 상시 조작 바·진행률·페이지 번호를 기본으로 깔지 않는다. 발표자가 키보드/리모컨으로 넘길 수 있게 하고, 화면 조작 UI는 사용자 요청이나 실제 사용 조건에 따라 선택한다. 제어 방법은 전달 메시지로 알려줄 수 있으며 모든 장에 안내를 넣을 필요는 없다.

기존 자료를 고칠 때 embedded 자산·유효한 출처·기존 조작과 원문의 의미를 보존한다. 수정 범위에 없는 내용을 요약 삭제하지 않는다. 최초 원본은 별도 결과 또는 복구 가능한 백업으로 보존한다. 사용자가 지정했거나 이번 작업에서 만든 작업본은 현재 내용을 확인하고 같은 파일에 후속 수정을 반영한다. 수정할 때마다 사본이나 승인을 요구하지 않는다. 대상이 불명확하거나 다른 작업의 변경과 충돌할 때만 확인한다. 파일 전달은 외부 호스팅 배포 권한을 뜻하지 않는다.
