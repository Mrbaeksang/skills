# 하나로 전달되는 HTML

기본 결과는 서버·빌드·설치 없이 직접 열리는 HTML 하나다. 제작 중에는 자산과 소스를 분리해도 되지만 전달본은 CSS, JS, 폰트, 이미지, SVG를 내장한다. JS/CSS CDN, 원격 font import, 상대 이미지 경로, 외부 SVG image, fetch에 필수 콘텐츠를 의존하지 않는다. 출처로 이동하는 링크는 실행 의존성과 다르다. 동영상처럼 큰 외부 자료는 임베드 재생을 오프라인 가능하다고 주장하지 말고 포스터/출처 링크와 제한을 알린다.

HTML/CSS와 작은 JavaScript로 충분하면 프레임워크를 도입하지 않는다. GSAP이 필요한 경우 선택한 공식 배포 버전의 코드를 내장하고 고지를 보존한다. 폰트도 라이선스/저작권 고지와 함께 내장한다. 폰트·이미지는 실제 출력에 필요한 크기와 굵기로 제한하고 파일 크기를 확인한다. 수정 폰트의 명칭/배포 조건을 확인하지 않고 임의로 subset하지 않는다. 사용자 비밀·로컬 경로·제작 중 메모는 전달본에 남기지 않는다.

선택한 서체를 CSS font-family에 적는 것과 실제 제공하는 것은 다르다. 기존 자료에 사용 가능한 내장 폰트가 있으면 보존하고, 새 자료는 배포 가능한 공식 font 파일을 data URI의 @font-face로 넣는다. 시스템 폰트 목록만 둔 결과를 동일한 타이포그래피가 보장되는 전달본이라고 보고하지 않는다. 폰트 확보가 불가능하거나 사용자가 시스템 폰트를 선택한 경우에만 fallback을 사용하고, 대체 서체에서 다시 검수한 결과와 기기별 차이를 알린다.

기본 조작은 이전/다음, 현재 위치, 목차 또는 바로 이동, 키보드, 목표 발표 화면과 노트북 높이에서 접근 가능한 버튼이다. fullscreen은 사용자 동작으로만 요청하고 거부돼도 발표가 가능해야 한다. 새로고침/직접 장 링크는 같은 장으로 복원한다. 입력창·편집 중인 내용·링크의 키 조작을 navigation이 가로채지 않는다. 비활성 장은 focus와 접근성 트리에서 제외한다. 사용하지 않는 빈 notes/editor/panel 기능을 만들지 않는다.

발표 노트는 숨겨 보여도 파일에 포함되면 수신자가 읽을 수 있다. 비공개 메모를 그대로 포함하지 않는다. 인쇄를 제공하면 숨겨진 장·단계별 등장 요소도 모두 표시하고, 한 장이 잘리거나 과도한 빈 페이지가 생기지 않도록 별도 print CSS를 둔다. 정적 읽기/인쇄에서 애니메이션 재생을 기다려야 본문이 보이는 구조는 피한다.

기존 자료를 고칠 때 embedded 자산·유효한 출처·기존 조작과 원문의 의미를 보존한다. 수정 범위에 없는 내용을 요약 삭제하지 않는다. 원본은 덮어쓰지 않고 새 파일을 만들며 이미 있는 새 결과도 확인 없이 덮어쓰지 않는다. 파일 전달은 외부 호스팅 배포 권한을 뜻하지 않는다.
