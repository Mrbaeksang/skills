# 동네 도서관 앱 — 화면 과제 입력

평가용 합성 제품이다. 실제 서비스나 고객 데이터가 아니다.

- 사용자는 동네 도서관 회원이다. 스마트폰(390px 폭)에서 쓴다.
- 핵심 행동은 빌린 책의 반납일 확인, 대출 연장, 예약한 책의 도착 확인이다.
- `content.json`은 화면에 그대로 쓸 실제 데이터다. 제목 길이·상태 분포를 바꾸지 않는다.
- 브랜드 가이드는 없다. 로고는 텍스트 "동네서가"만 쓴다.
- API는 없다. 화면은 단일 HTML 파일이며, 데이터는 파일 안에 넣거나 같은 폴더의 JSON을 읽는다. 외부 CDN·폰트·네트워크는 쓰지 않는다.
- 상태 규칙
  - 대출 `dueDate`가 오늘(2026-11-27) 이전이면 연체다.
  - 3일 이내면 반납 임박이다.
  - `renewable:false`이면 연장할 수 없다(사유는 `renewBlockedReason`).
  - 예약 `status`는 `waiting`(대기 순번 `queue`) 또는 `ready`(수령 기한 `pickupBy`)다.
